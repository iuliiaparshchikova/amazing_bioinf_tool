# amazing_bioinf_tool
Small toolkit for working with FASTQ, FASTA and BLAST output files

## Installation

```bash
git clone git@github.com:iuliiaparshchikova/amazing_bioinf_tool.git
cd amazing_bioinf_tool
```
## Usage

```python
from amazing_bioinf_tool import (
    filter_fastq,
    convert_multiline_fasta_to_oneline,
    parse_blast_output,
)
```
